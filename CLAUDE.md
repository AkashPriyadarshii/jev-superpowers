# Project Guidelines - jev-superpowers

An agentic skills framework upgrading software development methodologies (`obra/superpowers`) with TypeSafe AI Jev System One typed decisions.

## Architecture
- **Framework Type**: Drop-in agent skills repository (`~/.agents/skills/`)
- **Engine**: TypeSafe AI Jev System One (`jev-1.13.0` / `jev-latest`)
- **Ecosystem Tooling**: Orchestrates `jev-scout`, `jev-axi`, `git-jev`, `jev-guard`, `supercov`
- **Cost**: ₹0 for core skills, fractions of a cent ($0.042/M tokens) per Jev fan-out decision.

## Development Workflow
- **Verification**: `pwsh ./scripts/test.ps1` or `bash ./scripts/test.sh`
- **Code Standards**: Strict YAML frontmatter adhering to standard Agent Skills format
- **Tone**: Human senior systems developer. Zero corporate fluff, zero AI marketing buzzwords.

## Rule of Precedence
1. Global Rules (`~/.gemini/GEMINI.md` / `C:\Users\saves\AGENTS.md`)
2. Project Rules (`AGENTS.md` / `CLAUDE.md` in repository root)
